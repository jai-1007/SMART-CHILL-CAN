# ChillMilk Can

Portable milk cooling and temperature monitoring system for rural and remote transportation.

### Target
- Capacity: 30–40 L
- Temperature: 4–8 °C
- Duration: 6–12 hours

### Components
- ESP32
- DS18B20
- 5 °C PCM
- HDPE
- PUF Insulation

### Files
- `sketch.ino` – Temperature monitoring & calibration code
- `diagram.json` – Wokwi circuit
- `libraries.txt` – Required libraries
